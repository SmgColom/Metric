# Metric Solutions 🏅

Professional sports timing website for a Colombian company 
specializing in multi-sport event chronometry using RFID technology.

## 🔗 Live Site
[metric-omega.vercel.app](https://metric-omega.vercel.app)

## 🛠️ Built With
- Next.js
- React
- SCSS Modules

## ✨ Features
- Fully responsive design
- SEO optimized
- Multi-page site (Home, About, Services, Events, Blog, Contact)
- RFID chip timing services showcase
- Dynamic event results fetched from external timing API
- Blog section with live running news pulled from external news API
- Contact form

## 🔌 API Integrations
- **Events**: Real race results and rankings fetched dynamically 
  from an external sports timing API
- **Blog**: Latest running news and trends pulled automatically 
  from an external news API — no manual content updates needed
